# 📖 Project Overview
AI Career Coach is an application helping the user to analyze their CV, identify their current and missing skills, and make a learning roadmap based on the target role.

The application uses RAG, Chains, and Output Parser to analyze the CV and compare the candidate's skills with job requirements and learning roadmaps

---

# ✨ Features
1. Upload CV as a PDF.
2. Enter the target role.
3. Analyze the CV.
4. Extract the candidate's current skills.
5. Extract and consider the candidate's experience.
6. Compare skills with job requirements.
7. Identify missing skills.
8. Recommend a learning roadmap.
9. Suggest suitable jobs.
10. Create an improvement plan.
11. Return the analysis in structured JSON format.

---

# 🛠️ Technologies Used
Python, Streamlit, PyTorch, Hugging Face Transformers, Mistral Nemo Instruct, LangChain, Structured Output Parser, PyPDFLoader, RAG
, Prompt Template, JSON

# ⚙️ Installation
Install the required libraries in the Kaggle notebook:

# !pip install -q streamlit langchain-community langchain-core pypdf accelerate transformers

Fetch the public IP to use as the password for LocalTunnel:

# !curl ipv4.icanhazip.com

Install LocalTunnel:

# !npm install -g localtunnel

---

# 🚀 Usage
Run the Streamlit application on Kaggle and expose it using LocalTunnel:

# !streamlit run app.py & npx localtunnel --port 8501

After running the application:
1. Open the LocalTunnel URL.
2. Enter the public IP shown by curl ipv4.icanhazip.com if LocalTunnel asks for a password.
3. Upload your CV as a PDF.
4. Enter your target role.
5. Click Analyze Career.
6. Get the career analysis from the AI.

The application provides:
Current Skills, Missing Skills, Recommended Roadmap, Suggested Jobs, Improvement Plan
